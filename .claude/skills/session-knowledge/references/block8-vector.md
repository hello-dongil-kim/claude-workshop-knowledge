## EXPLAIN

> 🎙️ **설명 대본 (이대로 말하듯, ≤6줄 — 낭독 금지, 요약만)**
> - 심화 트랙 — 여기서만 **API 키·파이썬·비용** 등장. 기본으로 충분하면 건너뛴다.
> - 기본 트랙 두 한계(대규모에서 다 못 읽음 / 매번 재검색)를 푼다 — **임베딩 색인**하면 수천 개도 즉시 검색.
> - 부품: **임베딩 · 벡터스토어(LanceDB) · 청킹 · 하이브리드(벡터+BM25 RRF) · 재순위.** 하이브리드는 한국어에 특히 효과.
> - **멀티 LLM**: `common.py`의 `EMBED_PROVIDER`만 바꿔 OpenAI↔Gemini↔로컬 교체·분리 — 한 공급자에 안 묶인다.
> - 안전 필수: 키는 환경변수, 민감 노트 제외, venv·DB는 Vault 밖, 본 색인 전 작은 폴더로 스모크. 색인은 재생성 가능한 캐시.

기본 트랙(에이전트 검색)의 두 한계 — **대규모에서 후보를 다 못 읽음 / 매번 재검색** — 를 푸는 게 벡터 RAG다. 노트를 미리 **임베딩 색인**해두면 수천 개도 즉시 의미 검색된다.

### 부품

| 부품 | 역할 | 선택지 |
|---|---|---|
| **임베딩** | 문장 → 의미 벡터 | **OpenAI** 또는 **Gemini** 또는 **로컬**(멀티 LLM) |
| 벡터스토어 | 벡터 저장·검색 | LanceDB(로컬 파일, BM25 내장) |
| 청킹 | 검색 단위로 분할 | 마크다운 헤딩 인지 + 토큰 윈도우 |
| 하이브리드 | 벡터(의미)+BM25(키워드) RRF | 한국어에 특히 효과 |
| 재순위 | LLM이 상위 후보 재정렬 | OpenAI/Gemini 등 |

### 멀티 LLM — 한 곳에 안 묶인다

`common.py` 상단의 `EMBED_PROVIDER`만 바꿔 **OpenAI ↔ Gemini ↔ 로컬**을 갈아끼운다. 임베딩과 재순위 LLM을 서로 다른 공급자로 둘 수도 있다(예: 임베딩 Gemini + 재순위 OpenAI). 한 공급자 장애·가격 변화에 묶이지 않는다.

> 📌 **변동 정보 (최종 확인: 2026-06-29)** — 모델명·단가는 바뀝니다. OpenAI는 <https://platform.openai.com/docs>, Gemini는 <https://ai.google.dev/> 확인. 비용: 노트 수천이라도 초기 색인 보통 1달러 미만, 증분은 거의 0.

### 안전 (B0~B5와 달리 여기선 필수)

- 키는 환경변수로만. 민감 노트 제외. venv·DB는 **Vault 밖**(`~/.local/share/knowledge-search`).
- 본 색인 전 **작은 폴더로 스모크** + 비용 가늠. 막히면 `templates/safety-cost-checklist.md`.
- 색인은 **재생성 가능한 캐시.** 원본 노트가 진실의 원천(B0~B5와 동일 원칙).

### 코드

`templates/knowledge-search/` — `common`(설정·청킹·임베딩) · `index`(증분·prune·FTS) · `search`(하이브리드·필터·재순위) · `moc`(KMeans 자동 클러스터) · `setup.sh`/`setup.bat` · `refresh.sh`. Vault 경로 한 줄만 바꾸면 작동.
