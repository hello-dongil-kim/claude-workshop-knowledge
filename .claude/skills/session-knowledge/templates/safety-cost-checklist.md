# 안전 · 비용 · 오류 체크리스트 (1장) — 심화(B8) 벡터 RAG 전용

> 기본 트랙(B0~B5, 에이전트 검색)은 **추가 설치·키·비용 0**(Claude Code 외) — 이 체크리스트가 필요 없다. 이 문서는 **심화 B8(임베딩 벡터 RAG)** 에서만 본다.

심화 색인을 만들기 전·중·후에 한 번씩. 막히면 이 표대로 Claude에게 시킨다.

## 🔐 안전 (시작 전 확인)

- [ ] **API 키는 환경변수로만.** 노트·코드·파일에 키를 적지 않는다. OpenAI=`OPENAI_API_KEY`, Gemini=`GEMINI_API_KEY` (Windows는 `set`). 공급자는 `common.py`의 `EMBED_PROVIDER`로 선택.
- [ ] **민감 노트 제외.** 고객정보·비밀번호·계약서 등이 든 폴더는 인덱싱 대상에서 뺀다(`--target`로 안전한 폴더만, 또는 해당 폴더 분리).
- [ ] **원본은 손대지 않는다.** 이 시스템은 노트를 *읽기만* 한다. 인덱스(DB)는 Vault 밖 캐시 — 망가져도 `index.py --rebuild`로 재생성.
- [ ] **인덱스·venv는 Vault 밖**(`~/.local/share/knowledge-search`). 동기화 폴더에 두지 않는다.

## 💸 비용 (임베딩 = 유일한 과금 지점)

- 임베딩은 OpenAI API로 과금. **노트 수천 개라도 초기 1회 보통 1달러 미만**, 이후 증분은 거의 0.
- [ ] 불안하면 **작은 폴더로 먼저** 인덱싱해 실제 청구를 가늠.
- [ ] 재인덱싱(`--rebuild`)은 전체를 다시 임베딩 = 다시 과금. 평소엔 증분(기본)만.
- 비용 0으로 가려면: `common.py` 상단을 로컬 임베딩 모델로 교체(선택, 설치 부담↑).

## 🚑 흔한 오류 → 해결 (Claude에게 그대로 시키기)

| 증상 | 원인 | 시킬 말 |
|------|------|---------|
| `OPENAI_API_KEY ... 없습니다` | 키 미설정 | "키를 환경변수로 설정하는 법 알려주고 확인해줘" |
| `ModuleNotFoundError` | venv 활성/설치 안 됨 | "setup을 다시 돌리고 올바른 venv 파이썬으로 실행해줘" |
| `Permission denied` (스크립트) | 실행 권한/경로 | "이 스크립트를 올바른 방법으로 실행해줘 (OS 확인 후)" |
| 검색 결과 0 | 인덱싱 안 함 / 경로 틀림 | "VAULT 경로가 맞는지 확인하고 인덱싱부터 다시 해줘" |
| 한글 검색이 좀 엉성 | BM25가 한국어 형태소 미분석 | "하이브리드 대신 의미 위주로, 필요하면 `--rerank` 붙여 다시 검색해줘" |
| DB가 너무 큼 | 증분 add 단편 누적 | "LanceDB optimize로 인덱스를 압축해줘" |
| Windows에서 안 됨 | `setup.sh` 사용 | "Windows니까 `setup.bat`로 셋업해줘" |

## 🇰🇷 한국어 검색 — 정직한 기대치

- **의미검색(벡터)** 은 한국어에서 잘 작동한다(임베딩이 뜻을 잡음).
- **키워드(BM25)** 는 기본 토크나이저가 공백 기준이라 조사·어미("은/는/이/가") 때문에 한국어 정확 매칭은 약하다 → 하이브리드에서 **보조** 역할.
- 정확한 고유명사 검색이 중요하면: 그 단어를 그대로 질의에 넣고 `--rerank` 사용. (심화: 형태소 분석기 전처리 — 선택)
- 검증법: 내가 답을 아는 **한글 질문 5개**로 직접 검색해 체감 품질을 확인.
