# Vault CLAUDE.md — 검색 규칙 스니펫

session-obsidian에서 만든 Vault `CLAUDE.md`에 아래를 덧붙인다. Claude(와 미래의 나)가 "찾을 때 어떻게 찾을지"를 매번 알아서 따르게 하는 규칙.

```markdown
## 지식 검색 규칙

자료를 찾을 때는 grep 한 단어로 끝내지 말고 **에이전트 검색**을 한다:

1. 질의를 동의어·상위어·한영 병기로 **넓힌다** (집값→부동산·전세·주거).
2. frontmatter(`type`/`tags`/기간)로 **좁히고**, 후보 많으면 `_moc/_index.md`에서 주제를 먼저 고른다.
3. 후보 노트를 **실제로 읽고**, 질문 의도에 맞는 순으로 정렬.
4. 각 결과에 **근거 문장 1줄 인용**. 확실치 않으면 "관련 약함" 표시(추측 금지).

- 위 절차는 `knowledge-find` 스킬로 굳혀둠 — "지식 검색: 질문"으로 호출.
- 자료가 많이 쌓이면 `_index.md`·`_moc/`를 갱신한다(검색 자체는 색인이 없어 항상 최신).
- (심화·선택) 노트가 수천+이고 매번 빠른 시맨틱 검색이 필요하면 벡터 RAG 사용:
  `"$HOME/.local/share/knowledge-search/.venv/bin/python" <코드경로>/search.py "질문" --rerank`

원본 마크다운이 진실의 원천. 벡터 색인(쓸 경우)은 `index.py --rebuild`로 재생성 가능한 캐시.
```

> `<코드경로>`는 심화 트랙(B8)에서 knowledge-search 코드를 둔 위치. 기본 트랙만 쓰면 마지막 줄은 빼도 된다.
